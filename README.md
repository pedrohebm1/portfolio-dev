# 🚀 Portfólio Pessoal

Portfólio desenvolvido para apresentar meus projetos, trajetória e habilidades como Desenvolvedor Full-stack. 

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias como:

* **Framework:** [Next.js](https://next.js/) (React)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Componentes / UI:** [Shadcn UI](https://ui.shadcn.com/)

---

## 📂 Sobre o Site

O portfólio conta com seções estruturadas para destacar:
* **Início:** Apresentação profissional e objetivo de carreira.
* **Projetos:** Destaque para aplicações desenvolvidas (como *Glancedash* e *Postfire*), contendo tecnologias utilizadas e links para repositórios.
* **Sobre mim:** Breve resumo da minha trajetória, interesses e foco atual.
* **Habilidades Técnicas:** Divisão clara entre competências de *Backend & Cloud* e *Frontend & Mobile*.
* **Contato:** Links diretos para E-mail, GitHub e LinkedIn.
